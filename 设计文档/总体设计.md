# fight-1 的 AI 学习笔记 · 个人博客网站总体设计

> 版本：v0.1（总体设计稿，仅设计、未开发）
> 作者：fight-1
> 目标：一个用来沉淀 / 汇总 / 检索 AI 学习资料的个人博客。
> 内容主线：Agent · Skill · MCP · LLM · Token 优化 · UI 设计 · 提示词 · RAG 等。

---

## 0. 一句话定位

一个**内容优先、视觉炫酷、可切换主题**的"AI 学习资料库型博客"——既是你自己的第二大脑，也能对外分享。本质是「带数据库的笔记 Wiki + 博客」。

---

## 1. 用户与目标

| 项 | 说明 |
|---|---|
| 站主 | fight-1（你） |
| 主要用途 | 把 AI 学习过程中的资料、踩坑、总结结构化沉淀下来，便于日后检索和复习 |
| 次要用途 | 对外展示学习轨迹，可能分享给同好 |
| 内容形态 | 以 Markdown / MDX 为主的长文笔记，少量代码、图表、公式 |
| 非目标 | 不做电商、不做社区论坛、不做重型 CMS 后台（内容用文件管理即可） |

---

## 2. 信息架构（IA）

```
站点
├─ 首页（Hero + 最新笔记 + 分类入口 + 数据概览）
├─ 笔记（列表/检索页）
│   ├─ 全部
│   ├─ 按分类：Agent / Skill / MCP / LLM / Token优化 / UI设计 / 提示词 / RAG / 多模态 / 工程化
│   └─ 按标签
├─ 笔记详情
│   ├─ 正文（MDX：代码高亮、公式、图表、思维导图）
│   ├─ 右侧 TOC（目录，可点击跳转 + 阅读进度）
│   ├─ 上一篇/下一篇
│   └─ 相关推荐（同标签/同分类）
├─ 标签云 / 知识图谱（可视化关联）
├─ 搜索（全站全文检索，结果高亮）
├─ 收藏（浏览器本地，无需登录）
├─ 关于（fight-1 的介绍 + 这个站怎么用）
└─ 友链 / 资源（可选）
```

### 内容分类（Taxonomy）建议

| 分类 | 说明 / 例子 |
|---|---|
| Agent（智能体） | 多智能体编排、规划-执行、反思循环、Agent 框架对比 |
| Skill（技能） | 各类 Agent Skill 的设计范式、复用、踩坑 |
| MCP（模型上下文协议） | MCP Server/Client、常见连接器、自建 MCP |
| LLM（大模型） | 模型能力边界、选型、微调、推理 |
| Token 优化 | 上下文压缩、提示词瘦身、缓存、批处理、成本 |
| UI 设计 | 设计系统、炫酷交互、动效、可访问性 |
| 提示词工程 | Prompt 模板、结构化输出、Few-shot |
| RAG / 向量 | 检索增强、向量库、切片策略 |
| 多模态 | 文生图/视频/3D、视觉理解 |
| 工程化 | 部署、评测、可观测、成本控制 |

> 分类与标签解耦：**分类是固定书架（10 个左右），标签是自由贴纸（可无限）**。

## 4. 视觉设计规范

> 核心理念：**因为站名叫 fight-1，主题不做成"换色"，而做成一套「战甲皮肤库」**——每个皮肤是一个完整的视觉世界（背景、配色、字体、装饰、动效全换），可随时一键切换、全站联动。皮肤之间共用同一套布局与组件，只换"皮肤变量"，所以开发成本低、视觉差异大。

### 4.1 主题皮肤库（"战甲皮肤"总览）

| 皮肤 | 战斗形态 | 主色板 | 字体调性 | 标志性装饰 | 适合场景 |
|---|---|---|---|---|---|
| **星空 · 星海征途** | 星际战士 | 深空蓝黑 + 星青/星紫 | 几何无衬线 | 星点、星云光晕、玻璃卡 | 默认炫酷、科技笔记 |
| **古风 · 墨剑江湖** | 执剑侠客 | 宣纸米 / 深墨夜 + 朱砂红 | 书法 / 宋体 | 水墨笔触、朱砂印章、卷轴 | 人文、随笔、长文 |
| **科技 · 赛博战甲** | 机甲战士 | 近黑 + 霓虹青/品红 | 等宽科技体 | 网格、扫描线、切角框、glitch | 硬核、工程化、代码 |
| **玄幻 · 灵蕴修真** | 修真者 | 深紫金 + 灵紫/鎏金 | 宋/隶标题 | 流动灵气光带、符文角饰 | 沉浸、故事感内容 |
| **极简 · 素白**（基底） | 纯粹阅读 | 大留白 + 单强调色 | 无衬线 | 极简分割线 | 阅读模式 / 兜底 |

> 每个皮肤都支持 **亮 / 暗** 两种底（如古风有"宣纸日"与"深墨夜"），所以实际视觉组合数 = 5 皮肤 × 2 底 ≈ 10 套。

### 4.1.1 星空 · 星海征途（Cosmic，默认）
- **概念**：fight-1 是穿越星海的战士。深空渐变背景（`#05060f → #0b1026`），静态星点 + 缓慢漂移的星云光晕（CSS `radial-gradient` 动画，`prefers-reduced-motion` 时关闭）。
- **主色**：`--bg #070a16`；`--surface rgba(255,255,255,.05)`（玻璃）；`--text #e8ecff`；`--accent` 星青 `#5eead4` / 星紫 `#8b5cf6`。
- **字体**：标题 `Space Grotesk`；正文 `Inter` / `思源黑体`；代码 `JetBrains Mono`。
- **装饰**：毛玻璃卡片 + 细星点边框；Hero 区漂浮星球 / 星座连线；卡片 hover 星光描边。

### 4.1.2 古风 · 墨剑江湖（Ink Wuxia）
- **概念**：执剑行走江湖的侠客。两套底——「宣纸日」`#f5efe1` / 「深墨夜」`#1a1c1a`；水墨笔触分隔线、朱砂印章 logo、卷轴感卡片。
- **主色**：`--accent` 朱砂 `#b23b2e` / 黛青 `#2f4858`；纸 `#f5efe1`；墨 `#20211f`。
- **字体**：标题 书法体（`站酷快乐体` / `钟齐流江毛笔` / `思源宋体`）；正文 `思源宋体` / `思源黑体`。
- **装饰**：宣纸纹理（SVG 噪点）、印章红角标、竹/远山 SVG 边角；卡片如展开卷轴。

### 4.1.3 科技 · 赛博战甲（Cyber）
- **概念**：机甲战士的 HUD 界面。近黑 `#06080d` 底，霓虹网格背景、扫描线、glitch 故障标题、四角切角框卡片。
- **主色**：`--accent` 霓虹青 `#00f0ff` + 品红 `#ff2e88`；`--bg #06080d`；`--surface #0d1117`。
- **字体**：标题 `Orbitron` / `Rajdhani`；正文 `Inter`；代码 `JetBrains Mono`。
- **装饰**：背景网格线、四角括号框、扫描线动画、hover 时轻微 glitch 抖动。

### 4.1.4 玄幻 · 灵蕴修真（Xianxia Fantasy）
- **概念**：修真者灵气流转。深紫金主调，灵气流动光效（渐变流动）、符文边框、卷云纹。
- **主色**：`--accent` 灵紫 `#a855f7` + 鎏金 `#d4af37`；`--bg #120a1f`；`--surface rgba(168,85,247,.08)`。
- **字体**：标题 宋体 / 隶书感（`思源宋体` bold）；正文 `思源宋体`；代码 `霞鹜文楷等宽`。
- **装饰**：流动光带、符文角饰、粒子灵气上浮（轻量 CSS 动画）。

### 4.1.5 极简 · 素白（阅读基底）
- **概念**：纯粹阅读。大留白、克制分割线、`--accent` 单色可换。作为阅读模式与兜底皮肤。
- **主色**：`--bg #fbfbfa`；`--surface #ffffff`；`--text #1a1f29`；`--accent` 可切（青/紫/橙/绿）。

### 4.2 配色系统（CSS 变量 + 皮肤变量）
- 通用 token：`--bg / --surface / --text / --muted / --accent / --border / --glow`（光晕）。
- 每个皮肤 = 一组变量覆盖（`[data-skin="cosmic"] { --bg:...; --accent:... }`）。
- 亮/暗再叠一层（`[data-skin="ink"][data-theme="dark"] { ... }`）。
- 切换 = 只改 `<html>` 的 `data-skin` / `data-theme`，全站 200ms 过渡无闪烁。

### 4.3 字体
- 每皮肤自带字体配对（见 4.1.1~4.1.5）；中文用 `思源黑体 / 思源宋体` 兜底。
- 代码统一 `JetBrains Mono` / `Fira Code`（星空、赛博、极简）；古风/玄幻可用 `霞鹜文楷等宽` 更搭。

### 4.4 布局（通用，皮肤只换皮不改骨架）
- **首页**：顶部 Hero（站名 + 一句话简介 + **皮肤切换器**）→ 数据概览条 → 最新笔记卡片网格 → 分类快捷入口
- **列表页**：左侧分类/标签筛选侧栏 + 右侧卡片流；顶部搜索框
- **详情页**：左（可选大纲）中（正文）右（TOC + 进度）；移动端 TOC 收进悬浮按钮
- **栅格**：桌面三栏可折叠，移动端单栏

### 4.5 动效
- 页面切换：淡入 + 轻微上移（`prefers-reduced-motion` 时关闭）
- 卡片：hover 抬升 + 描边发光（星空/赛博/玄幻各有专属光效）
- 主题切换：背景色 CSS 过渡 200ms，无闪烁
- 滚动：章节进入视口渐显
- 皮肤专属：星空星点飘移、赛博扫描线、玄幻灵气流动、古风卷轴展开

### 4.6 皮肤切换器 UI
- 导航栏放一个「战甲」入口，展开为**皮肤选择面板**：每个皮肤一张预览色卡（小图 + 名称），点击即换。
- 记忆到 `localStorage`，下次访问还原；首访按系统偏好给默认（默认=星空·深空）。

## 5. 技术栈建议（重点推荐）

| 关注点 | 推荐 | 理由 |
|---|---|---|
| 框架 | **Astro** | 内容站性能最佳，默认零 JS，MDX 原生支持，生态成熟 |
| 样式 | **Tailwind CSS** | 主题用 CSS 变量 + Tailwind，切换成本低 |
| 内容 | **Markdown / MDX** | 写作即源码，Git 管理，天然版本历史 |
| 搜索 | **Pagefind**（构建期索引） | 静态站全文搜索，零后端，体积小 |
| 公式 | **KaTeX** | 快、轻 |
| 图表 | **Mermaid** | 架构/流程直接写文本生成 |
| 评论 | **giscus** | 免后端，借 GitHub Discussions |
| 部署 | **GitHub Pages / CloudStudio / Vercel** | 静态构建产物直接传 |
| 图标 | **Lucide** | 风格统一、轻量 |

> 备选：若更想要"文档感"，可用 **VitePress** 深度定制；若想要更强交互（P2 的 AI 助手），用 **Next.js**。综合看 **Astro 最稳**。
