## 3. 开发顺序（里程碑）

### P0 · 核心骨架（本阶段先做）
1. **脚手架**：初始化 Astro + Tailwind + MDX + RSS，配 `astro.config` / `tailwind.config`。
2. **皮肤系统**：`global.css` 写 5 皮肤 × 亮/暗 = 10 套 CSS 变量；`theme.js` 切换 `data-skin/data-theme` 并存 localStorage；`SkinSwitcher` 面板。
3. **布局与导航**：`BaseLayout` + `Nav`（logo fight-1、战甲、亮暗、搜索入口）。
4. **内容集合**：`content/config.ts` 定义 notes schema；放 2~3 篇示例笔记（覆盖不同分类）。
5. **页面**：首页（Hero + 数据概览 + 最新卡片 + 分类入口）、笔记列表、笔记详情（TOC + 进度 + 上下篇）、关于。
6. **代码高亮 + RSS**：Shiki 双主题；`rss.xml.js`。
7. **搜索**：生成 `/search.json`，搜索页客户端过滤（关键词高亮）。
> 验收：`npm run build` 通过；`npm run dev` 可浏览；4 种皮肤 + 亮暗可切换。

### P1 · 体验增强
- KaTeX 公式、Mermaid 图表、标签云/知识图谱、阅读时长/字数、相关推荐、收藏（localStorage）、giscus 评论、Pagefind 全文搜索替换自建索引、分类/标签页完善。

### P2 · 炫技差异化
- 本地 RAG 问答（基于本站笔记）、知识图谱 3D 力导向、PWA 离线、自定义主题编辑器、版本 diff 视图、多语言。

## 4. 皮肤与主题实现要点
- 全部颜色用 CSS 变量：`--bg/--surface/--text/--muted/--accent/--border/--glow`。
- `<html data-skin="cosmic|ink|cyber|xianxia|minimal" data-theme="dark|light">` 切换。
- 每皮肤一套变量块，亮/暗再叠一层；切换 200ms 过渡无闪烁。
- 首访：按 `prefers-color-scheme` 定暗亮，默认皮肤 = `cosmic`（星空）。
