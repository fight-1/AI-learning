# 动效与交互炫酷设计方案（fight-1 博客 · 第二阶段）

> 状态：仅设计方案，未开发。
> 目标：从"换色 + 简单光晕"升级为**「活着」的动态背景 + 可玩的强交互**。
> 原则：所有动效统一走 CSS 变量（--accent / --glow / --bg…），换肤即换色；尊重 `prefers-reduced-motion`；触屏/低端机有降级。

---

## 0. 总览：我们要补的"炫酷层"

| 维度 | 现状（P0） | 本方案目标 |
|---|---|---|
| 背景 | 每皮肤 1 套 canvas 动画 | 每皮肤 **多种背景可切换**（星/银河/流星/像素…），做成背景库 |
| 光标 | 系统箭头 | **自定义发光光标**（拖尾、随皮肤变形） |
| 卡片 | 3D 倾斜 + 光晕 | + **磁吸吸附** + **点击涟漪** + **6 种排布舞台** |
| 标签 | 文字云（字号分级） | **3D 标签关系球**（可旋转/缩放/跳转） |
| 交互 | 收藏/筛选 | + **完整拖拽系统**（排序/跨区/占位/回弹） |

---

## 1. 背景动态库（每皮肤多种背景，可切换）

把背景从"固定 1 套"升级为**背景模式库**：皮肤决定基调，背景模式可独立选择，组合出更丰富的观感。

### 1.1 背景模式清单（按皮肤分组）

| 皮肤 | 背景模式（建议） | 视觉描述 |
|---|---|---|
| 星空·星海征途 | ① 星点飘移 ② **银河横带** ③ **流星雨** ④ **像素星空** | ① 缓慢漂移的星点；② 一条横贯的星云带 + 星点；③ 间歇流星划过；④ 低分辨率像素化星点（复古 8-bit 感） |
| 科技·赛博战甲 | ① 霓虹网格扫描 ② **像素矩阵雨**（数字雨）③ 全息脉冲 ④ 电路走线 | ② 落下的字符流（青/品红）；③ 同心脉冲环扩散 |
| 玄幻·灵蕴修真 | ① 灵气上浮 ② **符文流转球** ③ 莲华绽放 | ② 缓慢自转的符文环；③ 中心莲花开合光晕 |
| 古风·墨剑江湖 | ① 墨晕扩散 ② **山水长卷** ③ 飞花 | ② 横向卷动的远山水墨剪影；③ 飘落花瓣 |
| 极简·素白 | ① 微光浮尘 ② **极简粒子线** | ② 细线连接的漂浮粒子（弱存在感，阅读友好） |

### 1.2 实现要点
- **canvas 状态机**：`bg.js` 改为多模式，按 `data-bg` 切换渲染器；切换背景不重建 DOM，只换绘制函数。
- **像素风做法**：离屏低分辨率 canvas（如 1/6 尺寸）绘制后放大 + `image-rendering: pixelated`，得到复古像素颗粒。
- **背景切换器**：在「战甲」面板里，每套皮肤下再列背景模式小色卡；选择存 `localStorage`（键 `bg`）。
- **性能**：背景与光标/粒子共用 `requestAnimationFrame` 节流；后台标签页 `visibilitychange` 暂停绘制。

## 2. 自定义发光光标（替换系统箭头）

- **方案**：`cursor: none`（仅指针设备），用 DOM + 跟随逻辑画发光圆点（复用现有 `cursor.js` 的拖尾球），叠加一层"交互态"外环。
- **随皮肤变形**：
  - 星空 → 柔光圆点 + 细光晕
  - 赛博 → 方块/十字准星光标
  - 玄幻 → 符印圆环
  - 古风 → 朱砂圆点
  - 极简 → 细描边圆
- **交互态**：悬停可点击元素（a / button / [data-tilt]）时光标放大成环或变形，提示"可操作"。
- **降级**：触屏设备（无 hover）或 `reduced-motion` → 保留系统箭头，不隐藏。

---

## 3. 卡片磁吸吸附（Magnetic）

- **行为**：指针进入卡片"磁吸半径"时，卡片向指针方向轻微位移（`translate` 几像素~十几像素）并微放大；指针离开回弹归位。
- **与 3D 倾斜叠加**：磁吸负责"位移吸引"，`[data-tilt]` 负责"旋转"，两者用不同变量（磁吸 `--mx/--my` 偏移量，tilt 用 `--rx/--ry`）合成，互不打架。
- **强度参数化**：`--magnet: 0.18`（位移系数），不同皮肤可调（赛博/玄幻强一点，极简弱/关）。
- **降级**：触屏/reduced-motion 关闭磁吸，仅保留倾斜或都关。

---

## 4. 点击涟漪波纹（Ripple）

- **全局 click 涟漪**：监听 `document` 点击，在坐标处生成扩散圆环（DOM 元素 + CSS `@keyframes`），颜色取 `--accent`，~600ms 消散。
- **皮肤变体**：像素皮肤改成"像素方块爆裂"，赛博改成"扫描框扩散"。
- **作用范围**：按钮、卡片、导航项、分类 chip 通用；大可点区域（卡片）涟漪从点击点发起。
- **实现**：轻量纯 CSS/JS，无需库；用事件委托 + 防抖避免堆叠。

---

## 5. 3D 标签关系球（取代/增强标签云）

- **形态**：标签/分类节点分布在可旋转的 3D 球体表面（Three.js 或 CSS 3D），节点大小=热度、颜色=所属分类。
- **关系**：节点间连线表示"共现"（同一篇笔记同时出现的标签），形成知识网络。
- **交互**：拖拽旋转、滚轮缩放、点击节点跳转 `/tags/xxx`；hover 高亮相邻节点。
- **入口**：标签页（`/tags`）顶部放关系球，取代纯文字云；首页可放一个迷你版。
- **技术选型**：推荐 **Three.js**（真 3D、性能好、易做拖拽旋转/缩放）；节点位置用球面均匀分布算法（Fibonacci sphere）。低配/降级时回退到现有字号标签云。
- **数据**：由 `content` 集合在构建期统计标签共现，生成 `tags-graph.json` 喂给前端。

## 6. 卡片排布舞台（6 种模式）

为**笔记浏览区**（首页"最新笔记" + 笔记列表）提供"舞台模式"切换器，用户任选一种排布方式浏览笔记。每种都是完整的空间交互，而不仅是网格。

| # | 模式 | 排布 | 选中/交互行为 | 实现建议 |
|---|---|---|---|---|
| 1 | **纵深叠排展开** | 卡片沿 z 轴前后分层错位（近大远小） | hover/选中卡片前移放大到最前，其余保持层次不散 | CSS 3D `translateZ` + JS 计算每层 z/缩放 |
| 2 | **扇形展开** | 以底部同支点为轴呈扇形散开 | 选中卡片抬起放大，其余仍贴扇形位 | CSS `rotate` 围绕支点 + `translateY` |
| 3 | **圆柱环绕** | 卡片围成圆柱环形，可整体旋转 | 正面（朝向视角）卡片自动放大；拖拽旋转圆柱 | CSS 3D 圆柱 or Three.js |
| 4 | **球面排布** | 卡片分布在球体表面 | 选中单张前移（不放大整个球），球可转 | Three.js 平面贴球 or CSS 3D 球面 |
| 5 | **螺旋排布** | 沿螺旋线逐层升高排列 | 选中卡片单独前移，螺旋可转 | JS 算螺旋坐标 + CSS 3D |
| 6 | **波浪矩阵** | 保持网格，行高随波浪函数起伏传递 | 单选卡片"查看"后波浪归位；hover 起波 | CSS/JS 波浪相位 + `translateY` |

- **切换器**：笔记列表页顶部放"舞台"下拉/图标组（网格/纵深/扇形/圆柱/球面/螺旋/波浪），选择存 `localStorage`。
- **降级**：圆柱/球面/螺旋等重 3D 在 reduced-motion 或低端机自动回退到"网格"。
- **统一**：所有模式卡片复用同一套 `NoteCard` 组件 + 现有磁吸/倾斜/涟漪，只改外层容器布局算法。

## 7. 拖拽系统规格（按"讲清对象/接收区/反馈/结果"来定义）

> 小提醒已收到：拖拽不说"做拖拽"就完事，要写清**拖什么、拖到哪、拖动时什么样、松手后怎样**。

### 7.1 适用范围
- 笔记列表内**手动排序**（自定义顺序）
- **跨分类转移**（把笔记拖到另一分类接收区）
- **收藏管理**（收藏页内排序 / 拖出取消收藏）

### 7.2 功能清单与行为定义

| 功能 | 对象（拖什么） | 接收区（拖到哪） | 拖动反馈 | 松手结果 |
|---|---|---|---|---|
| 拖动排序 | 单张笔记卡 | 同列表内的新位置 | 卡半透明跟随指针 + 原位留**占位符**空隙 | 落入新位置，顺序写入 localStorage；列表重排 |
| 拖放区域 | 笔记卡 | 高亮的"分类接收区 / 收藏区" | 接收区高亮描边 + 放大提示 | 笔记加入该区（改分类 / 加收藏），原位置移除 |
| 拖拽占位符 | 同上 | 实时插入点 | 占位符随指针在列表间滑动 | 松手占位符处落位 |
| 跨列表转移 | 列表 A 的卡 | 列表 B（另一分类） | 列表 B 高亮 + 指针处插入线 | 卡从 A 移除、加入 B，数据更新 |
| 边缘自动滚动 | 长列表内的卡 | 视口上/下边缘 | 接近边缘时列表自动滚动 | 卡可拖到当前看不见的区域落位 |
| 回弹归位 | 拖到"无效区/外部"的卡 | 无合法接收区 | 卡变红/抖动提示 | 松手**回弹**到原位，不改变数据 |

### 7.3 技术选型
- 推荐 **SortableJS**（成熟、自带占位/动画/跨列表/回弹），包体小；或自研 Pointer 事件拖拽（可控更强但工作量大）。
- 排序结果持久化：`localStorage`（手动顺序覆盖默认按日期），构建期内容顺序读取该覆盖。
- 跨分类转移需内容层支持（笔记 frontmatter `category` 运行时改 → 实际改文件或存 override），首版可先做"收藏区/排序"这类纯前端态，跨分类转移作为增强。

## 8. 技术选型与依赖

| 能力 | 方案 | 说明 |
|---|---|---|
| 3D 球/柱/螺旋/球面 | **Three.js** | 真 3D，性能好，拖拽旋转/缩放现成 |
| 精细时间线动效 | **GSAP** 或 anime.js | 波浪/扇形/纵深过渡更顺滑 |
| 拖拽 | **SortableJS** | 占位/跨列表/回弹开箱即用 |
| 粒子/背景/光标 | 原生 canvas 2D | 已有基础，扩展多模式 |
| 统一主题 | CSS 变量 + data-skin/data-theme/data-bg | 已有，扩展 `data-bg` |

> 注：Three.js / GSAP 会增加包体，静态站需做按需加载（仅进入对应页面/模式才 import），避免拖慢首屏。

---

## 9. 性能与降级策略

- **单一 rAF 调度器**：背景、光标、粒子、波浪共用一个渲染循环，按可见性/是否在视口节流。
- **reduced-motion**：关闭粒子、倾斜、波浪、旋转，保留静态布局 + 基础过渡。
- **触屏**：关闭自定义光标、磁吸；拖拽改为触控拖（SortableJS 支持）；卡片倾斜改轻量或关。
- **低端机**：3D 球/柱自动降为 2D 投影或文字云；背景降为静态渐变。
- **首屏优先**：Three.js/GSAP 按需动态 import，不进首屏 bundle。

## 10. 分阶段实施建议

- **P1.5（轻量炫酷，先做）**：背景库切换（含像素/银河/流星/矩阵雨） + 自定义发光光标 + 磁吸 + 点击涟漪。纯 canvas/CSS，风险低、见效快。
- **P2（重交互）**：6 种卡片排布舞台（先用 CSS 3D 做纵深/扇形/波浪，Three.js 做圆柱/球面/螺旋） + 3D 标签关系球 + 拖拽系统（SortableJS）。
- 每阶段独立可验收，不必一次全上。
